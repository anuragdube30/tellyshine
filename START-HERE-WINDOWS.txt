TELLY SHINE - READY TO RUN (WINDOWS, SQLITE)
=============================================

Docker/PostgreSQL is NOT required. The project now uses a local SQLite database.

1) Install Node.js 18+ if you do not already have it.

2) Open PowerShell in this project folder.

3) Install dependencies:
   npm install

4) Prepare the local database and admin account:
   npm run setup

   Or double-click setup-local-db.cmd.

5) Start the site:
   npm run dev

6) Open:
   http://localhost:3000
   http://localhost:3000/admin/login
